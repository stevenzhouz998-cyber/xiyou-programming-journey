# Xiyou Karpathy Gate

## Non-Negotiable Outcome

Build a genuine commercial-grade learning game. Do not target phase completion, screenshot similarity, configuration counts, or demo success.

## Before Work

1. Inspect the real current state.
2. State assumptions and gaps.
3. Define the player input, state transition, persistence, cross-system effect, failure behavior, and visible result.
4. Preselect the intended completion level.
5. Read the relevant rows in the [completion matrix](references/completion-matrix.md).
6. For visual work, read the [asset provenance rules](references/asset-provenance.md).

## Completion Levels

Use exactly one evidence-backed level:

1. Design complete
2. Configuration complete
3. Prototype demonstrable
4. One-level playable
5. System loop complete
6. Full-content verified
7. Commercial production complete

Do not skip levels or claim a feature is complete without evidence.

## Execution Gate

1. Write a failing test or executable acceptance check first.
2. Implement the smallest complete behavior, not a visible shell.
3. Verify success, failure, refresh, persistence, recovery, and cross-system behavior.
4. Verify player behavior in a real browser.
5. Audit the completion matrix.
6. Report evidence, exclusions, and remaining risks.

## Prohibited Shortcuts

- Do not treat a route, component, configuration, text, or animation as a system.
- Do not hard-code success or use hidden state disconnected from the visible editor.
- Do not infer thirty-level completion from one level.
- Do not make rewards, pets, equipment, or growth mere counters or decoration.
- Do not let assistance solve, rewrite, reorder, attack, or finish for the child.
- Do not use Flutter, SwiftUI, emoji, CSS art, div art, ASCII, placeholder boxes, hand-authored SVG, or code drawings as shipped assets.
- Do not claim commercial completion when evidence is missing.

## Reporting Contract

Always report the achieved completion level, evidence, unverified scope, and next blocking gap. If any mandatory row is unmet, explicitly report `not complete`.

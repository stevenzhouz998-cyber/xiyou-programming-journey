## 规则与完整行为

第四十四回原著背景是悟空解救受役僧众。依据 https://m.gushiwen.cn/guwen/bookv_68f285187377.aspx 。三位编号僧众与解除役使/登记离开两步是明确标注的教学抽象，不是原著人数、姓名或逐人登记情节。默认四行程序为公开名单、for、循环内 release(monk)、循环外 register(monk)。学习点为循环体缩进和动作先后，下一关再定义函数。本关的 release/register 是提供的学习命令，不要求定义函数。

名单为三位公开编号，允许重排而不要求固定顺序；允许空/缺/重复名单成为学习失败。两条动作可交换次序，末行动作可在循环内或外；参数可为当前 monk 或名单内固定编号，用于识别固定对象错误。至少一条循环体语句，不能用打印文本冒充成功。每位必须恰好先解除再登记。固定原著尾声不以学习失败改变。草稿可保留语法错误。

真实因果链：可见 CodeMirror/两个动作控件与末行缩进控件 → 保存草稿 → 受限 grammar 与 Worker AST 独立核验 → 同源 Pyodide exec、空 builtins → 逐动作事件（当前 monk、实际对象、动作、所在代码行）→ 按每位状态核验 → 保存运行 → 原子封存作品/正式证明/完成并解锁 W5-M2。同步 TS 推导仅供证据核对及导入验证，不冒充 Python 运行。逐步查看只播放已保存事件，不决定通关。帮助只解释已保存失败与概念，不改代码、不运行。

## 推荐的玩家体验

采用一个可见 Python 函数、四次明确调用，集中教授“调用传入的值成为本次参数，函数体必须实际使用参数”。沿用亮色绘本布局、CodeMirror、逐步观察与零惩罚失败。不增加新循环难题。

默认程序：

```python
def weather(order):
    record_weather('风')

weather('风')
weather('云')
weather('雷')
weather('雨')
```

孩子第一次运行会看到四次分别收到风、云、雷、雨，但实际四次都记录风。逐步观察同时展示“本次传入 → 参数 order → 实际记录”，定位第一个不匹配的调用。孩子将函数体固定值改为 `order` 后，同一函数按每次输入产生不同记录。

四次调用的值可编辑；漏调、重复、乱序、函数体写死常量均不能完成。公开参考提供风→云→雷→雨的故事顺序，不以背诵隐藏答案考核。学习成功同时要求有效参数绑定、函数体使用参数、实际执行四个正确记录；只匹配输出文字不能形成证明。

备选方案为继续使用旧版 for 循环依次传参，可复习循环，但会使本关同时出现循环变量与函数参数两个名字，削弱新概念的可见性。因此推荐四次直接调用。

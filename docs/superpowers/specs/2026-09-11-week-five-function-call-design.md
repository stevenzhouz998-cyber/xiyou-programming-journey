## 规则与完整行为

本关用一个无参函数封装三清观片段。默认可见源码为：

```python
def record_sanqing():
    record_arrival()
    record_names()
```

函数体依次表示“记录夜入三清观”“记录说明来历”，两步明确标注为教学回顾抽象，不冒充原著中的记录手续，也不要求孩子编写亵渎或战斗。`record_names()` 在本关特指记录悟空说明师徒是西行取经僧众，并非逐个姓名。默认程序的函数定义是正确的，但没有调用，所以真实执行只产生“函数已定义”，不产生两条教学记录。孩子在定义之后加入一次 `record_sanqing()`，才会执行函数体并完成本关。参数由 W5-M3 教授，本关任何形参、实参、返回值或自定义对象都不属于可编辑范围。

有限语法允许一个无参函数定义，函数体含一至两条本关动作，后接零至两条无参函数调用或本关动作；定义与调用之间及末尾可有普通空行，CRLF 与 LF 语义等价。也允许两条学习动作在函数体内外移动，以便用真实执行呈现边界错误。必须只有一份 `record_sanqing` 定义、函数体包含两步且顺序正确、两步均在函数体内、定义后恰好调用一次。漏调、重复调用、缺步、逆序和函数体外动作均是可执行学习失败；Python 语法错误、导入、打印、文件/浏览器/网络访问、循环、参数及其他名字由结构白名单拒绝。所有失败不扣生命、资源或星级。

真实因果链：可见 CodeMirror 与函数调用/动作顺序/函数体边界快捷控件修改同一源码 → 原子保存草稿 → 同步 AST 等价推导 → 独立 Worker 内同源 Pyodide AST 白名单和空 builtins `exec` → 回调产生函数定义、调用和实际动作轨迹 → 主线程逐字段核对 Worker 与当前源码 → 保存运行 → 可见观察失败 → 原子封存作品、formal-v3 证明与完成状态 → 持久解锁 W5-M3。stdout、预期文本、动画、React 状态和测试注入都不决定成功。逐步查看只播放已保存轨迹，提示只解释已保存失败，不编辑或运行。

Progress 升至 revision 14，新增独立 `w5-m2` session、`w5-m2-sanqing-function-record` 作品与 formal-v3 证明。W5-M2 正式保存和完成必须具有有效 W5-M1 formal-v3 前置。旧 W5-M2 完成迁移为 legacy-replay-only，不能伪造源码、运行、作品或正式证明；只有真实重玩可升级。完成后只读回放会再次真实执行已保存源码，同时不得改变原作品、证明或累计次数。刷新、导出导入、跨标签冲突、损坏源备份、保存失败恢复和家长摘要沿用协调器边界。

固定原著回顾为：悟空、八戒、沙僧夜入三清观，悟空随后说明他们是西行取经的僧众；故事接着进入车迟国祈雨比试。这是第四十四回夜入与第四十五回说明来历的教学摘录，不是完整事件链。它不由孩子代码生成，也不能把失败运行变成成功。场景使用经内置图像工具生成并完成 manifest 的三清观背景。

## 支持端与预算

- 桌面 Chromium / Firefox：1440×1024，鼠标与键盘。
- 手机 Chromium：390×844 与 320×844，触控与软键盘路径。
- 平板 WebKit：768×1024，触控与键盘。
- 键盘焦点可见，核心控件至少 44px；支持静音和减弱动画。
- W5-M2 lazy closure（含独立 Worker）不超过 3 MiB raw；同源 Pyodide 不超过 15 MiB；新场景不超过 1.25 MiB。
- 冷运行结果不超过 20 秒，热运行结果不超过 1 秒。Chromium 性能证据使用 10 Mbps 和 4 倍 CPU 降速；Firefox / WebKit 明确标注原生引擎兼容测量。

## 玩家行为与可见效果

四个区域初始留空，使用键盘与触屏均可操作的结构化选择，避免仅依赖拖拽。不引入自由聊天或 Python 新语法。

1. 任务：选择整理二调芭蕉扇的经过，决定范围。其他范围或改写目的不能满足本次任务。
2. 事实：从公开材料选择身份变化、真扇取得、被骗回及未完成通行的相关材料。可以合并为语义完整的事实卡，但不得用卡片顺序或数量充当完整性判断。卡片顺序不改变事实身份。
3. 限制：遵循材料和原著；材料不足时不编造。相互矛盾的改写要求必须实际阻塞，不可当作装饰性标签。
4. 格式：事件表或分步列表均合法，试运行真实改变呈现格式，不设置唯一形式答案。

旁边实时显示由孩子实际选择组合的说明书。点击试运行后冻结输入快照；本地整理器只从该快照中的事实生成内容，不补未选择的事实、不修正错选事实后冒充孩子作品。缺少范围/格式等必需项时可以显示对应缺项；不完整事实仍忠实展示已有部分。限制冲突明确报告并拒绝完成。

核验器与整理输出分开：对照公开材料检查完整性、真实性与无矛盾，首个阻塞定位到具体区域，孩子修正后重新运行。提示可解释概念及已有失败，但不得给出完整选项组合、替孩子添加材料、自动运行或授予完成。例：遗漏被骗回材料时，结果保留已有材料并说明“本次经过还不完整”，不能偷偷补齐结果。事实均正确而未选择限制，仍需孩子表达限制。

通关要求完整真实的说明书、实际成功试运行和成功持久化。成功作品可只读重放，提示“说明清楚能减少误解，回答仍需核实”。无装饰性奖励。有效 M3 正式证明解锁 M4，M4 玩法实现不包含在本次范围。
